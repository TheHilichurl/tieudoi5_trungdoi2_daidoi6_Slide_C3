## 🎯 Điểm Nhấn Kiến Trúc & Tính Năng Vượt Trội
1. **Đầy đủ 20 Slide Chuẩn Quốc Phòng:**
   - **Slide 01:** Trang bìa mở đầu (Hero Cover) nhận diện Đại học Đại Nam.
   - **Slide 02:** Mục lục toàn cảnh chương trình nghiên cứu.
   - **Slide 03 - 19:** Nội dung chuyên sâu với bố cục thiết kế đa dạng, trực quan, không lặp lại template.
   - **Slide 20:** Trang kết thúc (Conclusion), lời hiệu triệu thế hệ trẻ & cam kết hành động của sinh viên Đại học Đại Nam.
2. **Bộ Đếm Giờ Kép (Dual Real-time Timer):**
   - Đếm giờ trực tiếp trong chân trang slide (`.timer-text`).
   - Đếm giờ và điều khiển (Tạm dừng/Tiếp tục/Đặt lại) trên thanh điều khiển UI nổi (`#hud-timer-display`).
   - Tự động đếm giờ ngay khi mở trang thuyết trình.
3. **Thanh Điều Khiển Nổi (Floating HUD):**
   - Menu chọn nhanh 20 slide.
   - Phím tắt bàn phím tiện lợi: `→` / `Space` (Tiếp theo), `←` (Quay lại), `F` (Toàn màn hình), `H` (Ẩn/Hiện HUD).
   - Xuất file chất lượng cao: **Xuất PowerPoint Soạn Thảo (Native OpenXML PPTX)**, **PPTX 2K Ảnh**, và **PDF 2K Siêu Nét**.

## 🛠 Hướng Dẫn Chạy Cục Bộ (Local Development)
```bash
# Clone repository
git clone https://github.com/TheHilichurl/tieudoi5_trungdoi2_daidoi6_Slide_C3.git

# Di chuyển vào thư mục
cd tieudoi5_trungdoi2_daidoi6_Slide_C3

# Khởi chạy server tĩnh (Python)
python -m http.server 8080
```
Mở trình duyệt tại `http://localhost:8080` để trải nghiệm thuyết trình độ phân giải 1920x1080.
